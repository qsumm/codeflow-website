首屏主视觉 · 5 个方案

同题：一张图讲「从需求到交付」。选一个（或指出要混搭的部分），我再落到首页。

A · 轨道站点现版精修

一条轨道 + 四个阶段圆点，工作项从左侧进入，末端长出交付分支。信息最克制，像地铁线路图。

B · 流向管道由细到宽

一条从细变粗的流带：左边一个需求点，右边一片交付面。强调「输入小、输出大」，不用节点。

C · 传送带工业感

上下两条滚轮带，工作项小方块沿带前进，到右端码成一摞成品。强调「流水线」的物理直觉。

D · 形变一张卡变成交付物

左侧一张需求卡，中间三层渐隐重影表示「加工中」，右侧带对勾的交付卡。强调「同一个东西被做完」。

E · 进度时间轴横向进度条

一根进度条从 0 走到 100：左侧起点是需求，四个刻度是流水线阶段，右侧终点是一个已完成的交付徽章。最贴近「干到哪一步了」这一产品语言。
