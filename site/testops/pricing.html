License 机制

离线验签，模块位控制

①

激活码

base64(payload) + HMAC-SHA256 签名，payload 含机器指纹 / 有效期 / 模块位 / 签发时间。四类失败码：INVALID_SIGN / MACHINE_MISMATCH / EXPIRED / CLOCK_ROLLBACK（防改系统时间续命）。

②

四态门禁

disabled（未开启强制）/ valid / grace（宽限期，默认 14 天，新装实例不会被自己锁死）/ locked（核心 API 403 + 引导激活；登录与健康检查永不锁）。

③

模块位

当前 ops（全功能）与 pro（VIP 权益：定时任务等）。模块位关闭时导航与 API 同时不可见/403。

④

商业授权

独立商业许可（不受 AGPL 约束的源码授权）+ 定制 + 护航服务。定价与方案联系作者面议——本页不展示价格数字。
