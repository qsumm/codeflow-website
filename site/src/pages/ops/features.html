第一章 · 发现（FR-B / FR-C）

Agent 接管监控，指纹去重只报一次

①

采集与探活

FR-B1/B2/B5
  • install.sh 一键安装：launchd / systemd / nohup 三路径实测，60 秒内主机进列表
  • 6 项基础指标 + 磁盘/网络/TCP 扩展指标，默认 15s 周期上报
  • 4 型探针：HTTP / TCP / 进程 / HTTPS 证书剩余天数（自签内网证书可读）
  • 断网缓存 1h，恢复后按原始最大时间戳续传，聚合零重复
  • 零入站端口：Agent 主动回连，被监控机不开任何端口
②

告警引擎

FR-C1~C7
  • 指纹状态机：MD5(规则+排序标签+级别+查询)，触发/更新/留观/恢复/重启回放五态全单测
  • 3 类检测：阈值 / 3σ / 孤立森林（sklearn 缺失自动降级并如实标注）
  • 两级屏蔽 + 周期时段 + 标签四算子；事件不产生与只停通知两种语义分明
  • 通知三参数（重发间隔/封顶/恢复开关）+ 台账 + 渠道熔断（连续失败 5 次冷却 30 分钟）
  • Prometheus 轨：只读查询代理 + node_exporter 直采零改造接入
第二章 · 定位（FR-D）

AI 拿着工具去查，不是拿着笔去编

①

收敛与诊断

FR-D1/D2/D3
  • 两级收敛：规则聚类（同机 30 分钟窗）→ LLM 因果判定，LLM 不可用降级纯规则
  • 13 个只读工具：指标/探活/日志取证/案例/5 类历史查询——AI 只能查，不能编
  • 预算五件套：30 步上限 / 单工具 2 万字符 / 历史压缩阈值 / 单调 180s / 整体 900s 硬截止
  • 同参拒绝 + 末轮撤工具 + 空转强制收敛：三道防打转护栏
  • 三层留痕：思维链 / 工具瀑布 / 完整调用历史，全程 SSE 可回放
②

报告强约束

write_findings
  • 四段正文必填：结论 / 证据 / 推理 / 已排除的假设——空段即校验失败
  • 影响面四分类：已确认受影响（必带证据 token）/ 已确认健康 / 窗口内其它原因变化 / 没检查的
  • citations 逐条核对：指向不存在的 step 直接报错重试
  • 置信度确定性计分：按证据来源打分，关键证据缺失封顶——不让模型自评
  • 失败不覆盖：诊断失败不覆盖事件上已有的成功报告（D185 实测缺陷回归锁）
第三章 · 处置（FR-E）

九道护栏内才准动手，凭据用后即焚

①

护栏与执行

FR-E1/E2
  • 护栏判定顺序固定：denylist 硬拦（21 条，AI 与人均不可越过）→ 只读白名单放行 → suggest 拒绝 → auto 命中动作清单 → 人工凭据
  • 只读白名单防绕过：前缀匹配叠加写重定向检查 + curl 只认 GET 形状 + 任意管道进 shell 一律拒
  • 一次性审批凭据：只存 sha256、TTL 300s、含命令快照、用后即焚、重放被拒
  • 变更单五段 + copy-on-write 版本化；无显式验证段拒绝生成（杜绝把事实陈述当修复动作）
  • 审计可追溯：谁在何时以何种方式批准了哪一步
②

分级恢复与巡检

FR-411 / FR-D5
  • 4 类自愈动作白名单（刻意不含删除类），连续 2 次失败自动转人工
  • 9 条自愈护栏：限流 / 幂等 / 爆炸半径 / 依赖感知 / 无回滚不执行 / 发布窗口互斥 / 一键熔断 …
  • 定时巡检：磁盘/内存/探活/证书/负载/异常进程 8 项检查，异常自动开事件
  • 僵死兜底：变更单超 30 分钟无活动自动收敛，不永久挡住自愈
  • 执行边界：平台不代运维在生产机执行命令——远程通道列入 V2，是设计不是缺口
第四章 · 沉淀（FR-E3 / FR-426 / FR-427）

越用越懂你，且"懂"可以被度量

①

案例与订正

FR-E3 / FR-426
  • 案例库：事件关闭自动沉淀，向量召回 + 文本降级（5 分钟冷却防锁死）
  • 人工订正：报告可标跟进/观察/忽略，忽略必填理由——AI 原文永不被覆盖
  • 降噪复用：同主机被忽略过的历史，后续报告自动提示
②

技能与度量

FR-427
  • 8 个内置技能（3 方法论 + 5 领域）+ GitHub 导入 + 自动路由（fnmatch 命中即注入）
  • 技能带命令：本次诊断会话内临时白名单，denylist 硬边界不可越过，会话结束失效
  • 效果度量：加载次数 / 跟进率对照基线 / Token 中位数，样本不足如实标注
