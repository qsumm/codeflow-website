从安装到第一次交付

先起平台，再接执行器，然后派第一个需求。

按完整指南开始 →
1

起 CodeFlow 平台

准备一台 4C8G 的机器（Docker + Docker Compose），克隆仓库并构建。

git clone {{REPO_CLONE}} && cd CodeFlow/platform bash build.sh && bash bootstrap.sh
2

注册首个用户

打开注册页建组织，即成为管理员。

http://localhost:7001/register
3

接入执行器

在执行器节点（2C2G 即可）注册 runtime，接上你自己的模型通道。

python scripts/register_executor.py --agent-id 10001 \ --workspace-id 10000 --out runtime.env --provider claude
4

派第一个需求

在工单里指派数字员工，或绑定你的工单平台让需求自动流进来——剩下的交付在平台上看。

命令与开源仓库 README 逐字一致。最低配置 4C8G（全栈）/ 2C2G（执行器）。查看当前源码

分工

你做决定，数字员工做交付。

你只做两件事

01澄清需求——在工单里直接与数字员工对话，它经平台 MCP 实时读取工单后作答与追问
02验收交付——看真实代码、测试与交付报告，不通过就退回重跑

数字员工做其余

01分析与分支准备
02编码与测试（小队自动接棒，失败按预算重试）
03验证与交接（git 分支 + 可运行代码）
04交付结论回写工单平台（幂等，防重复）
