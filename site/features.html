每个能力都有真实运行验证。

CodeFlow 的功能清单不是路线图许愿——每一项都在真实系统里跑通过：工单自动接入、小队按 SDLC 模板接棒、交付结论回写源头平台。以下按「需求怎么进、活怎么干、结果怎么回」展开。

需求 → 交付

小队 / 数字员工 / SDLC 模板

能力说明
小队与多角色接棒分析与分支准备 → 编码与测试 → 验证与交付 → 交接评审；失败留痕、attempt 递增、可重新指派重启
SDLC 流程模板模板画廊 + 步骤级人工审批门禁；"事实不清时询问用户"内建在流程里
需求澄清对话在工单里直接与数字员工对话；数字员工经平台 MCP 实时读取工单（标题/状态/外部来源）后作答与追问
交付结论回写交付报告经备注通道回写源头工单平台，幂等 marker 防重复回写
执行控制暂停 / 恢复 / 执行记录 / 回收站 / 定时任务，全程审计留痕
开放接入

6 种 Agent 客户端 · 任意 Anthropic 兼容模型

Agent 客户端（开箱即用）

Claude Code · Codex CLI · Cursor CLI · Gemini CLI · Qoder CLI · Qoder CLI CN。Provider 适配层可插拔，新客户端按同一适配层扩展。

模型自由

任意 Anthropic 兼容端点：Claude / MiMo / GLM / Kimi / DeepSeek / 私有模型。ANTHROPIC_BASE_URL + ANTHROPIC_AUTH_TOKEN 即接，账单走客户自己的 API key。

平台集成

工单进得来，消息出得去

集成说明
禅道 ZenTao 18.10+绑定产品 → 需求/缺陷自动拉取入库 → 派发数字员工 → 交付备注回写源头。已真实闭环验证（建需求 → 开发交付 → 建缺陷 → 修复 → 回写）
Provider 抽象绑定/映射/回执全 provider 无关，新工单平台只需实现 ExternalWorkitemProvider
IM 机器人钉钉 / 飞书：群成员 @数字员工 即可对话
Chief of Staff平台智能管家：自动接单并拆解需求、调度数字员工协作交付、沉淀团队记忆
MCP平台 MCP 服务器（ainative）：令牌管理、技能包上传、个人记忆
执行器 runtime

纯标准库 Python，断线不丢进度

能力说明
协议闭环WS 七帧：心跳与能力声明、任务包下载（sha256 校验）、SDLC 逐步执行、澄清会话、交付备注上报
离线排队执行器离线走指数退避，上线自动唤醒；本地 SQLite 持久化运行状态，崩溃恢复
零依赖纯标准库实现（Python ≥3.11），只通过 WebSocket 协议帧与平台交互，不引用平台代码
单实例约束同一 executorId 单实例（服务端单会话，后来者顶掉先来者）
